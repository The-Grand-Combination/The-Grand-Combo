## Runtime files removed from core TGC in phase 3

- Timeline-only additive invention files: `TGC/inventions/NEW_*_inventions.txt`.
- Timeline-only units: `TGC/units/aircraftcarrier.txt`, `TGC/units/submarine.txt`.
- Timeline-only localisation carriers: `TGC/localisation/00_SUP_technology.csv`, `TGC/localisation/00_other_tech.csv`.
- Timeline-only Carrier/Submarine animation assets under `TGC/gfx/anims/`.
- The 50 late-tech `.tga` pictures copied under `TGC_Timeline_1966/gfx/pictures/tech/`.
- Timeline-only submarine/carrier and mixed UI DDS assets now carried by the submod.
- Timeline-only interface carrier files that were absent in `715ad72`: `buildunit.gui`, `country_military.gfx`, `ships.gfx`, and `unitpanel.gfx`.

## Core files restored to base/non-1966 in phase 3

- `TGC/common/defines.lua` no longer carries the 1966 end date in core.
- `TGC/common/buildings.txt` no longer carries timeline-only level 7-8 building changes in core.
- The five core `TGC/technologies/*_tech.txt` files no longer carry the Dumcem post-period technology branches.
- `TGC/interface/backend.gui` no longer shows the 1966 backend label in core.
- `TGC/interface/country_technology.gui`, `TGC/interface/buildings.gfx`, and the province building strip DDS files were restored to their base/non-1966 core versions.
- `TGC/interface/combat.gfx` and `TGC/interface/province_interface.gfx` were restored to base because their diffs were frame-count support for timeline-only strips/building levels.

## Core files split manually in phase 3

- `TGC/decisions/00_Setup.txt`: core end-game years were returned to base `1936`; generic spelling/newline fixes were preserved. The submod carries `TGC_Timeline_1966/decisions/00_Setup.txt` as a full override with the 1966 decision date.
- `TGC/inventions/navy_inventions.txt`: submarine-specific modifiers/effects were removed from core; generic invention key renames were preserved. The submod carries `TGC_Timeline_1966/inventions/navy_inventions.txt` as an override carrier file.
- `TGC/localisation/00_tech-invent.csv` and `TGC/localisation/00_technology.csv`: no additional extract was produced in phase 3 because the scripted key scan found no remaining lines matching the new 1966 tech/invention keys; generic localisation fixes remain in core.

## Known false-positive core references after cleanup

- Historical/flavour uses of the word `submarine`, such as the H. L. Hunley event text and Motala Verkstad description, are not timeline runtime unit references.
